# M1 Labs — Tcl Foundations

These labs accompany Part I.

## Lab 1 — First interpreter session

Start `tclsh`, execute simple `puts` and `set` commands, inspect `info patchlevel`, and record what each command returns.

## Lab 2 — Prediction notebook

For every example involving substitution and grouping, write down the expected result before execution. Keep incorrect predictions: they are useful evidence of which evaluation rule needs review.

## Lab 3 — IRC-flavoured data, no Eggdrop

Represent nicknames, channel names and simple messages using ordinary Tcl values and lists. No Eggdrop commands are permitted.

## Lab 4 — Small command-line bot model

Build a standalone Tcl program that reads simple commands from standard input and dispatches them to procedures. This is not an IRC bot. Its purpose is to establish concepts that later map naturally to bot command dispatch.

## Lab 5 — Defensive input

Feed unusual strings, whitespace, braces, brackets and dollar signs into your program as data. Observe when substitution occurs and, crucially, when it does not.

## M1 assessment

The assessment requires explanation as well as working code. Learners must demonstrate that they can predict evaluation and explain why their program behaves as it does.
