# M2 — Practical Tcl

M2 turns foundational Tcl knowledge into maintainable programs.

## Chapters

1. From scripts to programs
2. Namespaces
3. Namespace variables and state ownership
4. Organizing code across files
5. Packages and `package require`
6. Regular expressions
7. Glob and string pattern matching
8. Channels beyond basic files
9. Encodings, translation and buffering
10. Reliable cleanup with `try/finally`
11. Structured errors with `try`, `trap` and options
12. Argument expansion with `{*}`
13. Command prefixes and callbacks
14. Introspection with `info`
15. Functional list transformations
16. Configuration patterns
17. Reusable library design
18. Practical testing with `tcltest`
19. Refactoring MiniBot
20. M2 project and assessment

## Exit criteria

The learner can structure a multi-file Tcl application, define explicit namespace ownership, package reusable code, distinguish pattern-matching tools, manage channels and cleanup reliably, propagate structured failures, use command prefixes safely, inspect a running Tcl program, and test reusable modules.

M2 remains runnable in ordinary Tcl. Eggdrop-specific APIs begin later, but examples continue to use bot-shaped problems.
