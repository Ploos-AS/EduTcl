# Part I — Tcl Foundations

This part assumes no previous Tcl experience.

## Chapters

1. What Tcl is and why Eggdrop uses it
2. Installing Tcl and using `tclsh`
3. Your first Tcl program
4. Commands and words
5. Tcl's evaluation model
6. Variable substitution: `$name`
7. Command substitution: `[command]`
8. Braces, quotes and grouping
9. Strings and values
10. Numbers and `expr`
11. Lists: Tcl's central data structure
12. List operations
13. Control flow
14. Procedures
15. Arguments and return values
16. Scope and globals
17. Arrays
18. Dictionaries
19. Errors and `catch`
20. Files and basic I/O
21. Putting it together
22. M1 project and assessment

## Exit criteria

The learner can predict Tcl evaluation, explain substitution, choose correct grouping, manipulate lists safely, write procedures, use arrays/dicts, handle basic errors, and build a small standalone Tcl program without copying a recipe.

Eggdrop-specific commands are deliberately deferred. Sidebars explain where each concept will later appear in Eggdrop and TiCle.
