# Tests

EduTcl uses Tcl's standard `tcltest` package for executable course and project qualification where practical.

Run M1 tests with:

```text
tclsh tests/run.tcl
```

The M1 suite verifies command normalization, dispatch, structured list state, error behavior, Unicode, persistence, and that Tcl-looking user data remains data.

Tests are educational material too: learners should be able to read and explain them before M1 qualification.
